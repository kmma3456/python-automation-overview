# 기능 상세

Python Automation에 들어 있는 데스크톱 도구의 화면과 설정입니다.  
계정, 서버, 고객 작업 데이터는 적지 않습니다.

개요는 [README](../README.md), 구조는 [ARCHITECTURE.md](ARCHITECTURE.md)를 보면 됩니다.

---

## 1. 공통

### 실행 화면

- 작업을 시작하고 멈출 수 있습니다.
- 진행 상황이 로그 창에 쌓입니다.
- 작업 목록과 일정은 로컬 JSON에서 읽습니다.
- 브라우저 작업은 화면 스레드와 분리해서, 창이 멈추지 않게 합니다.

### 사용 권한

Place 작업 콘솔, Blog 작업 콘솔, 목록 순회 도구에 있습니다.

- 아이디와 비밀번호로 로그인합니다.
- 저장된 비밀번호는 해시와 비교합니다.
- 사용 기간이 끝난 계정은 작업을 시작하지 않습니다.
- 로그인하면 세션을 만들고, 실행 중에는 세션을 갱신합니다.
- 종료하면 그 세션을 해제합니다.

스토어 페이지 확인에는 이 로그인 단계가 없습니다.

### 설정

| 파일 성격 | 내용 |
| --- | --- |
| 작업 목록 | 이번에 돌릴 항목 |
| 일정 | 반복 간격, 실행 조건 |
| 환경 변수 | DB 호스트, 계정, 비밀번호, 포트 |

환경 변수는 `.env`에만 두고, 저장소에는 예시 키 이름만 둡니다.

### 배포

- PyInstaller로 Windows 실행 파일을 만듭니다.
- Chromium 런타임은 실행 파일 옆 폴더에 둡니다.
- 설정과 로그는 실행 파일 옆에 남습니다.

---

## 2. Place 작업 콘솔

장소 페이지를 조건에 맞게 열고, 연 결과를 로그로 남기는 GUI입니다.

- 로그인 후 작업 화면으로 넘어갑니다.
- 작업 목록과 일정을 읽어 브라우저 작업을 돌립니다.
- 페이지를 열고, 필요한 입력을 넣고, 화면 상태를 확인합니다.
- 시작, 중지, 로그 확인이 한 창에 있습니다.
- 실행 기록은 로컬 로그로 남습니다.

---

## 3. Blog 작업 콘솔

블로그 페이지 작업을 같은 방식으로 돌리는 GUI입니다. Place 작업 콘솔과 층이 같습니다.

- 로그인, 사용 기간, 세션 확인
- 작업 목록 · 일정 로드
- 브라우저로 페이지를 열고 결과를 기록
- 시작 / 중지 / 로그

같은 구조의 작업본이 하나 더 있습니다. 화면 구성과 설정 항목은 같고, 실행 위치만 다릅니다.

---

## 4. 목록 순회 도구

로그인 뒤 대상 목록을 위에서부터 열어 상태를 확인하고 기록하는 GUI 스크립트입니다. 도구마다 파일 하나입니다.

공통으로 있는 것:

- 로그인과 사용 기간 확인
- 대상 목록 로드
- 항목마다 페이지를 연 뒤 로그를 남김
- 항목 사이 대기
- 하루 처리량 상한과 진행 카운트 (해당 도구)

도구마다 확인하는 화면이 다릅니다. 이 문서에는 화면 이름과 조작 순서를 적지 않습니다.

---

## 5. 스토어 페이지 확인

상품 주소를 넣어 페이지가 열리는지 보고, 화면에 로그를 남기는 작은 GUI입니다.

- 상품 주소와 검색어를 입력합니다.
- 열 경로를 고릅니다.
- 횟수와 머무는 시간을 지정합니다.
- 브라우저를 보이거나 숨길 수 있습니다.
- 사용 권한 DB는 쓰지 않습니다.

고객 상품 주소와 검색어는 문서와 저장소에 넣지 않습니다.

---

## 6. 이 문서에 없는 것

- 서버 주소, DB 비밀번호, 계정
- 실제 작업 목록, 고객 키워드, 상품 주소
- 실행 중 쌓인 로그와 화면 캡처
- 개별 사이트의 클릭 순서
