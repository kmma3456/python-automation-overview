# 아키텍처

Python Automation은 여러 개의 Windows 데스크톱 프로그램입니다.  
역할은 나뉘어 있고, 실행 방식은 같습니다.

개요는 [README](../README.md), 기능은 [FEATURES.md](FEATURES.md)를 보면 됩니다.

---

## 1. 한 줄 구조

```text
운영자
  │
  ▼
Tkinter GUI
  │  시작 / 중지 / 로그
  ▼
진입점 (main)
  ├─ 환경 변수 로드
  ├─ 사용 권한 확인 (MySQL)     스토어 도구는 생략
  ├─ 세션 생성 · 갱신 · 해제
  └─ 작업 스레드
        │
        ▼
     core
        ├─ 브라우저 컨텍스트
        ├─ 페이지 열기 · 입력 · 상태 확인
        └─ 로그
        │
        ▼
     Chromium (Playwright)

로컬
  config/     작업 목록, 일정
  logs/       실행 기록
  .env        접속 정보 (저장소 밖)
```

GUI는 메인 스레드에 두고, 브라우저 작업은 별도 스레드에서 돌립니다. 로그는 큐나 콜백으로 창에 올립니다.

---

## 2. 프로그램별 모양

### Place 작업 콘솔 / Blog 작업 콘솔

패키지로 나뉩니다.

```text
main.py
  런타임 경로 설정
  DB 설정 로드
  로그인 · 사용 기간 · 세션
  gui 실행

gui/
  작업 화면
  시작 / 중지
  로그 창

core/
  브라우저 컨텍스트
  페이지 작업
  경로 · 로그

config/
  작업 목록
  일정
```

Blog 작업 콘솔의 두 작업본은 이 트리를 각각 가집니다. 역할 분리는 같고, 파일 위치만 다릅니다.

### 목록 순회 도구

도구마다 스크립트 하나입니다. GUI, 로그인, 순회가 한 파일에 있습니다.

```text
script.py
  환경 변수
  로그인 · 세션
  Tkinter 화면
  목록 순회
  Playwright
```

도구 사이 공통 패키지는 없습니다. 로그인과 세션 처리 방식은 작업 콘솔과 같습니다.

### 스토어 페이지 확인

```text
main.py
  입력 화면 (주소, 검색어, 경로, 횟수, 체류, 브라우저 표시)
  로그 창

core/
  페이지를 열고 상태를 로그로 남김
```

MySQL 로그인과 세션은 없습니다.

---

## 3. 사용 권한

Place, Blog, 목록 순회 도구가 공유하는 흐름입니다.

```text
로그인 창
  │
  ▼
MySQL에서 사용자 조회
  │
  ├─ 비밀번호 해시 비교
  ├─ 사용 기간 확인
  └─ 세션 토큰 저장
        │
        ▼
     작업 중 주기적으로 세션 갱신
        │
        ▼
     종료 시 세션 삭제
```

기준 시각은 외부 시각 서버로 맞춥니다. 접속 값(호스트, 사용자, 비밀번호, DB 이름, 포트)은 환경 변수에서만 읽습니다.

스토어 페이지 확인은 이 흐름 없이 입력값만 받아 브라우저를 엽니다.

---

## 4. 브라우저 실행

```text
실행 위치 계산
  ├─ 스크립트 실행: 프로젝트 폴더
  └─ 실행 파일: exe가 있는 폴더
        │
        ▼
Chromium 런타임 경로를 환경 변수로 지정
        │
        ▼
Playwright가 페이지를 연다
        │
        ├─ 입력
        ├─ 화면 상태 확인
        └─ 다음 항목 전 대기
```

런타임을 찾지 못하면 경고만 남기고, 경로는 로그에 찍습니다.

---

## 5. 설정과 비밀값

| 구분 | 위치 | 저장소 |
| --- | --- | --- |
| 작업 목록, 일정 | `config/*.json` | 운영 값은 공개 문서에 없음 |
| DB 접속 | `.env` / 환경 변수 | 커밋하지 않음 |
| 세션·쿠키 파일 | 실행 폴더 | 커밋하지 않음 |
| 로그, 디버그 이미지 | `logs/` 등 | 커밋하지 않음 |

코드 안의 기본 접속 값은 비어 있습니다. 값이 없으면 DB 연결은 실패합니다.

---

## 6. 배포

```text
pyinstaller 스펙
  │
  ▼
dist/
  실행 파일
  Chromium 런타임 폴더
  config/          필요한 도구만
```

실행 파일은 Python 설치 없이 동작합니다. 브라우저 런타임 폴더는 실행 파일과 같은 위치에 둡니다.

빌드 산출물, 가상환경, 캐시, 실행 로그는 소스 저장소에 넣지 않습니다.

## 7. 의존성

| 구성 | 쓰는 곳 |
| --- | --- |
| Python 3 | 전체 |
| Tkinter | 화면 |
| Playwright | 브라우저 작업 |
| mysql-connector | 사용 권한 확인 |
| bcrypt | 비밀번호 해시 비교 |
| ntplib | 기준 시각 |
| PyInstaller | Windows 실행 파일 |

스토어 페이지 확인은 화면과 Playwright만 사용합니다.

---

## 8. 데이터 흐름

```text
config / 화면 입력
        │
        ▼
   작업 한 건
        │
        ▼
   Chromium 페이지
        │
        ▼
   성공 · 실패 · 다음 행동
        │
        ▼
   GUI 로그 + 로컬 로그 파일
```

작업 결과는 이 프로그램 안에 모으고, 외부 분석 서버로 보내지 않습니다. 사용 권한 확인만 MySQL과 통신합니다.
